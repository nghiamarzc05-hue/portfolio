作品

卒業制作 ・ 個人開発

2D農場RPG「Nông Trại Miền Tây」

ベトナムの農村をテーマにしたブラウザで遊べる2Dゲームです。作物栽培と生き物集めとターン制バトルを組み合わせました。マップは8エリアあり、属性の違う生き物が16種類登場します。天気システムや釣り、料理などの要素も実装しています。データ保存にはFirebaseを使い、ログインすると別の端末でも続きから遊べます。

  • 8エリアのマップと16種類のクリーチャー収集・育成
  • ターン制バトル（スキルとクールダウン管理）
  • 作物栽培と料理、天候システム、釣りミニゲーム
  • Firebaseによるアカウント保存と自動セーブ

使用技術： HTML / CSS / JavaScript / Firebase / SVGアニメーション

個人開発

英語フラッシュカードアプリ「Flashcard English Master」

自分の英語学習のために作った単語学習アプリです。3Dで回転するフラッシュカードと、間隔反復（SRS）による復習管理で効率よく覚えられるようにしました。穴埋め練習や聞き取り入力、60秒のスピードマッチゲーム、4択クイズなど練習モードも複数実装しています。PWA対応でオフラインでも使えて、スマホにインストールできます。

  • 間隔反復（SRS）による復習スケジュール管理
  • 3Dフリップカードと品詞・IPA表示、音声読み上げ（英米の発音切替）
  • 穴埋め・聞き取り・スピードマッチ・4択クイズの練習モード
  • 学習ストリークと進捗管理、ダークモード、JSONバックアップ

使用技術： HTML / CSS / JavaScript / PWA（Service Worker） / Web Speech API / LocalStorage

デモを使う GitHubで見る
